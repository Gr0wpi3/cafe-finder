# ☕ Cafe Finder

A simple JavaScript web application designed to help users discover nearby cafes.

## 🚧 Project Status

**In Development**

The current version contains the initial user interface and JavaScript interaction. Real-time cafe data integration will be added in a later stage.

## ✨ Current Features

* Cafe Finder landing page
* Responsive layout
* Cafe-themed user interface
* "Find Cafes" button
* JavaScript click interaction
* Local development using Live Server

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Git
* GitHub
* VS Code

## ▶️ Running the Project

### 1. Clone the repository

```bash
git clone https://github.com/Gr0wpi3/cafe-finder.git
```

### 2. Open the project

Open the `cafe-finder` folder in VS Code.

### 3. Run with Live Server

Open `index.html` using the VS Code Live Server extension.

The application will be available locally in your browser.
